\section{Introduction}\label{sec:introduction}
While \href{https://www.citibikenyc.com/system-data}{\underline{Citi Bike}} data captures the pulse of New York City's urban mobility, its true value is often buried.
The raw data presents massive volumes and significant inconsistencies that make meaningful analysis difficult.

This project bridges the gap by transforming raw data into an interactive web application that provides immediate, actionable insights.
Powered by an efficient data pipeline that cleans, ingests, and precomputes statistics, the platform organizes these insights into four distinct views:
\begin{itemize}
    \item \textbf{Map:} A multi-layer spatial view of geographic features.
    \item \textbf{Temporal:} A time-series tool designed to reveal usage habits and trends.
    \item \textbf{Weather:} An interface correlating weather conditions with ridership.
    \item \textbf{Footprint:} A sustainability dashboard evaluating environmental impact.
\end{itemize}
To support data exploration, all views can be dynamically filtered by date-time range, user type, and bike type, in addition to featuring their own view-specific interactive filters.

Although the interface includes a structured guide to help users navigate it, the platform remains strictly exploratory.
Instead of forcing a narrative, it ensures that operators, city planners, and citizens can extract the answers most relevant to their needs.
